All notable changes to DocuMind Converter will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-01

### 🎉 Initial Release

#### ✨ Features
- **Multi-format Support**: Convert PDF, DOCX, PPTX, XLSX, HTML, images, and text files to Markdown
- **PDF Conversion**: Extract text from PDFs with OCR support for scanned documents
- **Word Documents**: Convert DOCX files preserving headings, tables, and formatting
- **PowerPoint**: Extract content from presentations with slide structure
- **Excel**: Convert spreadsheets to Markdown tables, CSV, or JSON
- **HTML**: Convert web pages to clean Markdown
- **Images**: OCR text extraction from images
- **Batch Processing**: Convert multiple files in parallel
- **CLI Interface**: Rich command-line interface with progress indicators
- **Document Info**: Display detailed document metadata

#### 🚀 Technical
- Python 3.10+ support
- Modular converter architecture
- Plugin system ready
- Configurable via environment variables
- Comprehensive logging
- Type hints throughout

#### 📚 Documentation
- Multi-language README (English, 简体中文, 繁體中文)
- API documentation
- CLI help system
- Usage examples
